# T-V3-034: Worker History + Task Execution Timeline

## 目标
补齐 v3 框架对子 Agent 执行历史的监控能力。后端新增 `worker_runs` 审计表，前端替换 AgentsPanel 为 WorkerHistoryPanel，并在 TaskDetailDrawer 增加 Execution Tab。

## 实现

### 后端
- `db/models.py`: 新增 `WorkerRun` 模型（id, worker_id, task_id, started_at, ended_at, status, duration_ms, result_summary, workspace）
- `store/base.py`: 新增 `create_worker_run`, `finish_worker_run`, `list_worker_runs`, `get_worker_run` 抽象方法
- `store/sqlalchemy_base.py`: 实现上述方法；`finish_worker_run` 计算 duration_ms，兼容 SQLite naive datetime
- `core/worker.py`: `_execute` 中任务开始时 `create_worker_run`，所有退出点（completed/failed/exception）调用 `finish_worker_run`
- `api/server.py`: 新增 3 个路由：
  - `GET /workers/history?limit=&offset=&worker_id=` — worker 执行历史
  - `GET /tasks/{id}/timeline` — 任务 EventLog 时间线（正序）
  - `GET /tasks/{id}/result` — 读取工作区 `zeus-result.json`
- `workspace/base.py`: 顺手修复缺少 `import asyncio` 的已有 bug

### 前端
- `WorkerHistoryPanel.vue`: 新组件，上方显示活跃 worker 卡片（实时 step/percent/heartbeat），下方显示 worker_runs 历史表格（status/duration/started/ended/result），支持 load more
- `Dashboard.vue`: agents tab 组件替换为 `WorkerHistoryPanel`
- `TaskDetailDrawer.vue`: 新增 `execution` tab，含 GitHub Actions 风格垂直时间线（task.started/progress/completed/failed 节点）+ zeus-result.json 原始结果展示
- `taskStore.ts`: 新增 `fetchWorkerHistory`, `fetchTaskTimeline`, `fetchTaskResult`
- i18n: 中英双语新增 agents.* 和 tasks.execution/timeline/result 键

### 构建
- `npm run build` 成功，产物已输出到 `scripts/api/static/`
